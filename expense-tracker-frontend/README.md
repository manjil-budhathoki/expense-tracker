# Paisa frontend

React, Vite and Tailwind. Use Node 22.12+ and run `npm install`, then `npm run dev`.

Set VITE_API_TARGET for the development proxy (default http://localhost:8000). Set VITE_API_BASE_URL before building when the backend is on a separate origin; configure backend CORS_ORIGINS accordingly. See the root README for full setup.

Checks: `npm run lint` and `npm run build`.
